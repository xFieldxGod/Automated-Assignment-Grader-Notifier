# สคริปต์พรีเซนต์: Automated Assignment Grader & Notifier

**รูปแบบ:** อัดคลิปหน้าจอ (screen recording) + เสียงบรรยาย
**ความยาวแนะนำ:** 6–8 นาที
**โทน:** กึ่งทางการ เป็นกันเองแต่เป็นมืออาชีพ

> วิธีใช้สคริปต์: แต่ละฉากมี 3 ส่วน — **[ฉาก]** บอกว่าจอโชว์อะไร, **พูด:** คือคำพูดจริง, **หมายเหตุ:** คือเคล็ดลับตอนอัด (ข้ามได้)

**พูด:**
> "สวัสดีครับ/ค่ะ ผม/ดิฉัน \[ชื่อ\] จากรายวิชา CSC490 วันนี้ขอนำเสนอโปรเจกต์ชื่อว่า **Automated Assignment Grader & Notifier** หรือ **ระบบตรวจการบ้านและแจ้งคะแนนอัตโนมัติ** ที่ผมพัฒนาขึ้นด้วยภาษา Python ครับ"

**หมายเหตุ:** พูดช้าเล็กน้อย ยิ้มได้ (ถ้ามีหน้าจอกล้อง) เริ่มต้นสำคัญที่สุด

## 🎬 ฉากที่ 3 — สถาปัตยกรรมระบบ (≈ 1 นาที)

**[ฉาก]** โชว์ไดอะแกรม 3 Bot ใน `README.md` (ส่วนต้นไฟล์) ซูมเข้าให้เห็นชัด

**พูด:**
> "ผมออกแบบระบบตามแนวคิด **Separation of Concerns** แบ่งงานเป็น 3 Bot ต่อกัน ส่งข้อมูลแบบ pipeline"
>
> **(ชี้ไปที่ Bot 1)** "Bot ตัวแรกคือ **Data Processor** ทำหน้าที่อ่านข้อมูลจาก Excel หรือ Google Sheet แล้วคำนวณคะแนนรวม เปอร์เซ็นต์ และเกรด ใช้ไลบรารี openpyxl กับ gspread"
>
> **(ชี้ไปที่ Bot 2)** "Bot ตัวที่สองคือ **Document Builder** รับข้อมูลจาก Bot 1 มาสร้างเป็นไฟล์ PDF รายคน ใส่สถิติของทั้งชั้นและอันดับให้ด้วย ใช้ fpdf2 และ reportlab เป็น backup"
>
> **(ชี้ไปที่ Bot 3)** "Bot ตัวสุดท้ายคือ **Communicator** ส่งอีเมลพร้อมแนบ PDF ให้นักศึกษาแต่ละคน ผ่าน Gmail API โดยใช้ไลบรารี ezgmail"
>
> "การแยก 3 ชั้นแบบนี้ทำให้ทดสอบแยกแต่ละส่วนได้ ถ้าอยากเปลี่ยนจาก Excel เป็น Google Sheet ก็แค่แก้ Bot 1 ตัวเดียว"

**หมายเหตุ:** ใช้เมาส์ชี้ / highlight แต่ละกล่องขณะพูด จะน่าดูกว่าพูดเปล่า ๆ

## 🎬 ฉากที่ 4 — เดินชมโครงสร้างไฟล์ (≈ 45 วินาที)

**[ฉาก]** เปิด VS Code / File Explorer โชว์โฟลเดอร์ `auto_grader/` ให้เห็น tree ด้านซ้าย

**พูด:**
> "มาดูโครงสร้างโค้ดกันครับ ในโฟลเดอร์โปรเจกต์ ผมจัดไฟล์แบบ flat ให้หาง่าย"
>
> **(ชี้ไฟล์ที่ละไฟล์)**
> - "`config.py` เก็บการตั้งค่าทั้งหมดในไฟล์เดียว ปรับคะแนนเต็ม เกณฑ์เกรด เทมเพลตอีเมล แก้ได้จากที่นี่ที่เดียว"
> - "`bot1_data_processor.py`, `bot2_document_builder.py`, `bot3_communicator.py` คือ 3 Bot ที่เล่าไป"
> - "`main.py` คือตัวประสานงาน เรียก Bot 1 → 2 → 3"
> - "โฟลเดอร์ `data/` เก็บ Excel ตัวอย่าง, `fonts/` เก็บฟอนต์ไทย THSarabun, `output/` จะเก็บ PDF กับ log ที่ generate ขึ้นมา"
